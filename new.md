# Танцевальный менеджер - Документация проекта

## 📋 Обзор

Веб-приложение для управления танцевальными коллективами.  
Позволяет создавать коллективы, добавлять участников, генерировать уникальные 6-значные коды, вести личный календарь занятости, а также управлять репетициями коллективов.

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Supabase (PostgreSQL + Auth + Edge Functions)
- **Библиотеки**: SweetAlert2, Font Awesome 6, Supabase JS Client

## 🗄 База данных

### Таблица users
```sql
id UUID PRIMARY KEY (auth.users)
email TEXT NOT NULL UNIQUE
last_name TEXT NOT NULL
first_name TEXT NOT NULL
patronymic TEXT
birth_date DATE NOT NULL
unique_code TEXT UNIQUE NOT NULL
nickname TEXT
telegram_chat_id BIGINT UNIQUE
role TEXT DEFAULT 'user'
created_at TIMESTAMP
updated_at TIMESTAMP
```

### Таблица dance_groups
```sql
id UUID PRIMARY KEY DEFAULT gen_random_uuid()
name TEXT NOT NULL
leader_id UUID REFERENCES users(id)
leader_name TEXT NOT NULL
description TEXT
created_at TIMESTAMP
updated_at TIMESTAMP
```

### Таблица group_members
```sql
group_id UUID REFERENCES dance_groups(id)
user_id UUID REFERENCES users(id)
joined_at TIMESTAMP
role TEXT DEFAULT 'member'
PRIMARY KEY (group_id, user_id)
```

### Таблица user_schedule (расписание)
```sql
id UUID PRIMARY KEY DEFAULT gen_random_uuid()
user_id UUID REFERENCES users(id) ON DELETE CASCADE
date DATE NOT NULL
start_time TIME NOT NULL
end_time TIME NOT NULL
status TEXT NOT NULL CHECK (status IN ('free', 'busy', 'unknown'))
created_at TIMESTAMP WITH TIME ZONE DEFAULT now()
updated_at TIMESTAMP WITH TIME ZONE DEFAULT now()
```

### Таблица rehearsals (репетиции)
```sql
id UUID PRIMARY KEY DEFAULT gen_random_uuid()
group_id UUID REFERENCES dance_groups(id) ON DELETE CASCADE
scheduled_date DATE NOT NULL
start_time TIME NOT NULL
end_time TIME NOT NULL
location TEXT
notes TEXT
created_by UUID REFERENCES users(id)
created_at TIMESTAMP WITH TIME ZONE DEFAULT now()
updated_at TIMESTAMP WITH TIME ZONE DEFAULT now()
```

**Индексы**: на `group_id`, `scheduled_date`.  
**RLS**: участники видят репетиции своих коллективов, лидеры могут создавать/удалять.

## 🔒 RLS Политики

### users
- SELECT: аутентифицированные
- INSERT: аутентифицированные
- UPDATE: свой профиль
- DELETE: аутентифицированные

### dance_groups
- SELECT: аутентифицированные
- INSERT: leader_id = auth.uid()
- UPDATE: leader_id = auth.uid()
- DELETE: leader_id = auth.uid()

### group_members
- SELECT: аутентифицированные
- ALL: пользователь является лидером коллектива

### user_schedule
- SELECT: auth.uid() = user_id
- INSERT: auth.uid() = user_id
- UPDATE: auth.uid() = user_id
- DELETE: auth.uid() = user_id

### rehearsals
- SELECT: участники группы (через group_members)
- INSERT: только лидер группы
- UPDATE: только лидер группы
- DELETE: только лидер группы

## 🎯 Функциональность (статус)

### ✅ Реализовано
- Регистрация и вход
- Генерация уникальных кодов
- CRUD участников (с никнеймом)
- Создание/редактирование/удаление коллективов
- Добавление/удаление участников в коллективы
- Показ только коллективов пользователя
- Статистика: количество коллективов, где лидер
- Поиск по коллективам
- Карточки с бейджами (Лидер/Участник)
- Роли: `admin` видит кнопку «Все участники», обычный пользователь — только «Профиль»
- Личный профиль с календарём на месяц
- Добавление событий (диапазон времени + статус: свободен/занят/неизвестно)
- Удаление событий
- Переключение месяцев
- **Управление репетициями коллективов:**
  - Лидер может назначить репетицию с выбором даты в календаре
  - Календарь показывает дни, где есть занятые участники (красный фон)
  - При выборе времени проверяется статус каждого участника именно на этот интервал
  - Отображается таблица статусов участников перед подтверждением
  - Лидер может удалять репетиции (из списка всех или быстрым удалением)
  - Участники видят список ближайших репетиций в просмотре коллектива
- Адаптивный дизайн под мобильные устройства
- **Тёмная тема для всех модальных окон SweetAlert2**
- **Telegram-уведомления:**
  - При создании репетиции всем участникам с заполненным `telegram_chat_id` отправляется уведомление
  - Отправка происходит через Supabase Edge Function (токен бота скрыт)
  - Пользователь может указать Telegram Chat ID при регистрации или в профиле

### ❌ Требует проверки/исправления
- Нет редактирования существующих событий в личном календаре (только удаление и добавление)

## 🔄 Навигация в приложении

1. После входа → **Дашборд** (коллективы пользователя)
2. Кнопка **«Профиль»** → личный календарь на месяц (с возможностью добавить/удалить события, редактировать данные профиля, указать Telegram Chat ID)
3. Если пользователь **админ** (role='admin'), дополнительно есть кнопка **«Все участники»** → таблица всех участников (CRUD)
4. Кнопка **«Назад к коллективам»** → возврат на дашборд
5. Кнопка **«Создать коллектив»** → модальное окно
6. Карточка коллектива → просмотр/редактирование/удаление (лидер видит кнопки, участник — только просмотр)
7. В просмотре коллектива лидер может:
   - Добавлять/удалять участников
   - Видеть информацию об участниках (кнопка «i»)
   - **Назначить репетицию** (календарь с выбором даты и времени)
   - **Удалять репетиции** (кнопка корзины рядом с каждой репетицией)
   - Просмотреть все репетиции через кнопку «Все репетиции»
8. Участник видит только список участников и ближайшие репетиции

## 📝 Важные особенности

- Никнейм не уникален, может быть пустым; отображается вместо ФИО, если задан.
- Администратор может просматривать и редактировать всех участников.
- Лидер коллектива может управлять своим коллективом (редактировать, удалять, добавлять/удалять участников, просматривать их личные данные, управлять репетициями).
- Участник видит только коллективы, где он состоит, и не может просматривать личные данные других участников.
- Уникальные коды генерируются автоматически.
- Нельзя удалить свой профиль из таблицы участников.
- При создании коллектива пользователь автоматически становится лидером и добавляется в group_members.
- Календарь в профиле позволяет планировать события с указанием времени и статуса занятости.
- **При назначении репетиции проверяется статус участников именно на выбранный интервал времени, а не на весь день.**
- Полная адаптация под мобильные устройства: сетка календаря, кнопки, заголовки подстраиваются под экран.
- **Все модальные окна выполнены в тёмной теме, соответствующей общему дизайну приложения.**
- **Telegram-уведомления отправляются только пользователям, указавшим свой Chat ID. Токен бота надёжно скрыт в Supabase Edge Function.**

## 🚀 Развёртывание

1. Скопируйте файлы проекта на сервер (или локально).
2. Создайте проект Supabase, выполните SQL-скрипты из документации для создания таблиц и RLS (включая таблицу `rehearsals`).
3. В `config.js` укажите `SUPABASE_URL` и `SUPABASE_ANON_KEY`.
4. Для работы Telegram-уведомлений создайте Edge Function `telegram-notify` (см. инструкцию ниже) и добавьте секреты.
5. Откройте `index.html` в браузере (рекомендуется использовать локальный сервер).

### 📱 Настройка Telegram-уведомлений

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. В Supabase Dashboard создайте Edge Function `telegram-notify`.
3. Добавьте секреты:
   - `TELEGRAM_BOT_TOKEN` – токен бота
   - `SUPABASE_URL` – URL вашего проекта
   - `SUPABASE_ANON_KEY` – anon key
4. Отключите "Verify JWT" в настройках функции.
5. Задеплойте функцию.
6. В `telegram.js` укажите URL функции.

## 👨‍💻 Разработка

Проект написан на чистом JavaScript без сборщиков, все модули подключаются в `index.html` в правильном порядке.

- Не забывайте обновлять RLS политики при добавлении новых таблиц.
